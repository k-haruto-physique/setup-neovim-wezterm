WezTerm CopyMode ★★ コピーモード

←↓↑→ / h j k lカーソル移動（IME ON 時は矢印推奨）
w / b / e単語 前進 / 後退 / 末尾
0 / ^ / $行頭 / 最初の非空白 / 行末
g / Gスクロールバック先頭 / 末尾
H / M / L画面 上 / 中 / 下
Ctrl+u / Ctrl+d半ページ ↑ / ↓
Ctrl+b / Ctrl+f1 ページ ↑ / ↓
PageUp / PageDown1 ページ ↑ / ↓（IME 無影響）
Home / Endスクロールバック先頭 / 末尾

y / Enterコピー + 終了
Esc / q / Ctrl+cコピーモード終了（コピーなし）
⚠ コピーモード中はカーソルが 黄色。黄色くなければ未起動 → IME を OFF にして再度 Ctrl+Shift+X。

Nvim モード遷移 ★★★ Neovim

Esc / Ctrl+[→ Normal（Ctrl+[ は IME 透過）
Ctrl+c→ Normal（autocmd 一部非発火）
iカーソル前で挿入
aカーソル後で挿入（append）
I行頭（最初の非空白）で挿入
A行末で挿入 ★頻出
o / O下 / 上に新行 + 挿入
s1 文字削除 + 挿入
S / cc行削除 + 挿入
cw単語末尾まで削除 + 挿入
c{motion}範囲削除 + 挿入（ciw, ci"）
C行末まで削除 + 挿入
r{char}1 文字置換（Insert に入らない）
v / V / Ctrl+vVisual 文字 / 行 / 矩形
:Command（Ex コマンド）
