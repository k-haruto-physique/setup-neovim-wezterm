# 練習ドリル — 段階別メニュー

`docs/nvim-manual.md` の「最初の 1 週間」を、**実際に手を動かす具体ドリル**に展開したもの。
理屈は `docs/vim-mental-model.md`、キーは `docs/keybinds.md`。本書は**反復メニュー**。

---

## 使い方（先に読む）

- **1 日 10〜15 分でいい**。可処分時間（朝晩各 1-2h）の頭で軽くウォームアップする想定。
- **急がない**。1 フェーズに 1 週間かけてよい。詰まったら前のフェーズに戻る。
- 練習台は**このリポジトリの docs**（壊しても `git checkout` で戻せる）か、捨てファイル。
- **詰まったら**: `Esc` 連打で Normal、効かなければ IME OFF（`Alt+~`）か `Ctrl+[`。

> 現在地の目安: 2026-05-22 開始なので、いまは **Phase 1〜2 のあたり**。下記は順序であって締切ではない。

---

## 🔥 毎日のウォームアップ（30 秒・全フェーズ共通）

新しい作業を始める前に、これだけ素振り:

1. `Space f f` で適当なファイルを開く
2. `gg` で先頭、`G` で末尾、`Ctrl+d`/`Ctrl+u` で上下スクロール
3. `Esc` を一度押して「いま Normal」を確認
4. `Space` を押して which-key を 2 秒眺める（メニューに目を慣らす）

これで「モードが分からない」事故が激減する。

## Phase 1 — 生存（モード・保存・移動）

**ゴール**: マウスと矢印キーだけでも、迷わず開いて・直して・保存できる。

### ドリル 1-A: モードの出入り（5 分 × 数日）

1. 捨てファイルを開く（`Space e` → `a` で新規 `scratch.txt`）
2. `i` → 何か打つ → `Esc`。これを 10 回。**`Esc` を押す手癖**を作る
3. `A`（行末入力）、`o`（下に新規行）、`I`（行頭入力）も各 5 回
4. 慣れたら `Esc` を `Ctrl+[` に置き換えて 5 回（IME 透過の安全弁を体に入れる）

> ✅ 合格: 「いま何モード？」と迷わず、無意識に `Esc` で Normal に戻れる。

### ドリル 1-B: 保存と終了（3 分）

- `i` で 1 行書く → `:w` で保存 → `:q` で閉じる
- わざと保存せず `:q` → 警告が出る → `:q!` で破棄して閉じる（**救済コマンドの体験**）

### ドリル 1-C: 移動の基礎（5 分）

- `w`（次の単語）と `b`（前の単語）で 1 行を行ったり来たり 10 往復
- `0`（行頭）↔ `$`（行末）を交互に
- `gg` ↔ `G`（ファイル端）を交互に
- 迷子になったら `zz`（画面中央に戻す）

## Phase 2 — 文法（動詞 + 名詞）★ ここが Vim の山

**ゴール**: `docs/vim-mental-model.md` の「動詞 + 名詞」が手で出せる。

### ドリル 2-A: 削除と変更（10 分・最重要）

捨てファイルに `function hello(name, age) { return name; }` のような行を用意して:

| 打つ | 起きること | 何を学ぶ |
|---|---|---|
| `diw`（単語上で） | 単語が消える | delete + inside word |
| `ciw` → 入力 → `Esc` | 単語を打ち直し | change + textobj |
| `di(` | `()` の中身が消える | inside カッコ |
| `ci"` | クォート内を書き直し | （文字列編集の定番） |
| `dd` | 1 行カット | 動詞 2 連 = 行全体 |
| `d$` / `D` | 行末まで削除 | 動詞 + モーション |

**各 5 回ずつ**。`u`（undo）で戻して繰り返せば 1 行で何度でも練習できる。

### ドリル 2-B: ドット `.` の威力（5 分・必修）

1. `foo` が複数ある行 / ファイルを用意（`foo bar foo baz foo`）
2. 最初の `foo` で `ciw` → `xxx` → `Esc`
3. `w` や `/foo Enter` で次の `foo` へ
4. **`.` を押すだけ**で `xxx` に変わる。これを最後まで繰り返す

> ✅ 合格: 「修正 → 移動 → `.`」のリズムが手に馴染む。これが体感できたら Vim の入口は突破。

### ドリル 2-C: コピー＆貼り付け（5 分）

- `yy`（行コピー）→ `p`（下に貼る）/ `P`（上に貼る）
- `yiw`（単語コピー）→ 別の場所で `viw` → `p`（選択範囲に上書き貼り）
- OS クリップボードへ: Visual で範囲選択 → `"+y`、別アプリで Ctrl+V

## Phase 3 — 実作業（LSP・検索・整形）

**ゴール**: 実際の SQL / Python / Lua / Markdown 編集を Vim だけで回す。
詳細は `docs/lang-workflows.md`。

### ドリル 3-A: コードを「読む」（10 分）

このリポジトリの `nvim/lua/plugins/markdown.lua` を開いて:

- `K`（カーソル下の関数の説明） ※ Lua なので LSP が効く
- `g d`（定義へジャンプ）→ `Ctrl+o`（元の位置へ戻る）
- `Space s s`（ファイル内のシンボル一覧でアウトライン把握）

### ドリル 3-B: 検索して直す（10 分）

- `Space /`（プロジェクト全文検索）で `transparent` を検索 → ヒットを開く
- ファイル内 `/NONE Enter` → `n`/`N` で巡回 → `:noh` で消す
- バッファ内全置換: `:%s/NONE/none/g` → `u` で戻す（**`:%s` の体験**、本番では使い所を選ぶ）

### ドリル 3-C: 整形を体感（5 分）

- 適当な `.py` か `.lua` をわざとガタガタにインデント → `:w` → 自動整形で揃う
- 揃わない時 `:ConformInfo` で「何が走るはずか」確認（`docs/lang-workflows.md`）

## Phase 4 — 効率化（慣れてきたら）

**ゴール**: 「速い」を体感する小ワザ。急がず、必要を感じたら取り込む。

| 技 | 何 | 使い所 |
|---|---|---|
| レジスタ `"0p` | yank 専用棚から貼る（`dd` に上書きされない） | コピー→別行削除→貼りで事故った時 |
| `f` / `t` + `;` | 行内ジャンプの反復 | 1 行内のピンポイント移動 |
| `*` | カーソル下の単語を即検索 | 変数の出現箇所を追う |
| `ci(` `di{` 等 | カッコ・ブロック単位編集 | コード編集全般 |
| `>` `<` を Visual で | 範囲インデント | コードブロックの字下げ |
| マクロ `qa…q` → `@a` | 操作を録画して再生 | 定型の繰り返し（`.` で足りない時） |

> マクロは強力だが Phase 4 で十分。`.`（ドット）で足りるうちは無理に使わない。

## 🎓 卒業チェックリスト

下記が**無意識で**できたら、もう「Vim が使える」と名乗っていい:

- [ ] `Esc`（or `Ctrl+[`）で迷わず Normal に戻れる
- [ ] `ciw` / `ci"` / `di(` で単語・クォート・カッコ内を編集できる
- [ ] `.`（ドット）で直前の修正を繰り返せる
- [ ] `Space f f` / `Space /` でファイルと文字列を探せる
- [ ] `Shift+L` / `Shift+H` でファイルを行き来できる
- [ ] `g d` / `K` でコードを読める
- [ ] `dd` 後の `p` 事故を `"0p` で回避できる（or 原因を理解している）
- [ ] 詰まっても `:q!` / `u` で必ず復帰できる安心感がある
