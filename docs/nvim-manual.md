# Neovim (LazyVim) 操作マニュアル

このリポジトリの LazyVim セットアップ用、**実用最低限の操作ガイド**。  
キーバインド網羅版は `docs/keybinds.md` 参照。  
本ドキュメントは「**初心者がコード閲覧から始めて慣れる**」フロー専用。

---

## 🗺 全体像: 3 つのモード

```
┌─────────────────────────────────────┐
│  Normal モード（基本）                │
│  - 移動、削除、コピー、コマンド入力     │
│  - Esc を押すといつでもここに戻る       │
│                                     │
│   ↓ i / a / o / A など              │
│                                     │
│  Insert モード（文字入力）             │
│  - 普通のエディタ感覚で入力できる       │
│                                     │
│   ↓ Esc                             │
│                                     │
│  Command モード（: で開始）            │
│  - :w 保存 / :q 終了 / :LazyExtras 等  │
└─────────────────────────────────────┘
```

**最重要原則**:
- 困ったら `Esc` 数回 → Normal モードに戻る
- 困ったら `Space` を押す → メニューが下に出てヒントが見える

## 🏠 ホーム画面（Dashboard）への戻り方

`nvim` 単体で起動すると **Dashboard**（LazyVim ロゴ＋メニュー）が出る。
ファイル開いた後にあそこへ戻りたい時：

### 方法 A: 全ファイル閉じる

```
:bufdo bd<Enter>
```

→ 開いているファイルを全部閉じる → Dashboard 表示。

### 方法 B: 一旦 nvim 終了して再起動

```
:qa<Enter>      （全部閉じて nvim 終了）
nvim            （PowerShell からまた起動）
```

### 方法 C: Dashboard コマンド直接

```
:Dashboard<Enter>
```

または

```
:Alpha<Enter>   （alpha-nvim プラグインが入ってる場合）
```

LazyVim では `:Dashboard` で出るはず。試してダメなら方法 A 推奨。

## 📂 VSCode 風サイドバー（ファイラ）

### 起動

```
Space → e
```

画面左に**ディレクトリツリー**が出る。↑↓ で選択、Enter で開く。**VSCode のサイドバーと完全に同じ使い勝手**。

> ℹ️ **現行の `Space e` は snacks.nvim の explorer**（LazyVim 既定）。下表の `H`(隠しファイル)・基本操作は snacks でも同様だが、`R`(リフレッシュ) は snacks には無い・代わりに `I` で gitignore 表示トグル・`?` で全キー一覧。**neo-tree を使いたい場合は `:Neotree` コマンド**で開く（下表は neo-tree のキー）。

### neo-tree（`:Neotree`）内のキーバインド（よく使うのだけ）

| キー | 動作 |
|---|---|
| ↑ / ↓ | カーソル移動 |
| `Enter` or `o` | ファイルを開く / フォルダ展開 |
| `Space` | プレビュー |
| `a` | 新規ファイル / ディレクトリ作成 |
| `d` | 削除（要確認） |
| `r` | リネーム |
| `y` | ファイル名コピー |
| `H` | 隠しファイルの表示トグル |
| `R` | ツリー再読み込み |
| `q` | neo-tree 閉じる |
| `Space e` | トグル（もう一度押すと閉じる） |

### マウスでも動く

neo-tree 内は**クリックでも動作**。当面はキーバインドを覚えずマウスで OK。

### ペイン間の移動

neo-tree（左）とエディタ（右）の間を行き来：

| キー | 動作 |
|---|---|
| `Ctrl+w l` | 右へ（エディタへ） |
| `Ctrl+w h` | 左へ（neo-tree へ） |
| `Ctrl+w w` | 次のウィンドウへ巡回 |

または LazyVim キー:

| キー | 動作 |
|---|---|
| `Ctrl+h` | 左へ |
| `Ctrl+l` | 右へ |
| `Ctrl+k` | 上へ |
| `Ctrl+j` | 下へ |

## 🔍 検索（3 種類を使い分ける）

### ① ファイル名で開く（Telescope find_files）★★★

**プロジェクト内のファイルを fuzzy 検索して開く**。VSCode の `Ctrl+P` と同じ。

```
Space → f → f
```

→ ファイル名検索ボックスが出る → 部分文字列タイプ → ↑↓ で選択 → Enter で開く。

### ② プロジェクト全文 grep（Telescope live_grep）★★★

**全ファイル内の文字列を検索**。VSCode の `Ctrl+Shift+F` と同じ。

```
Space → /          （または Space → s → g）
```

→ 検索ボックスに文字列を入力 → リアルタイムで全マッチが下に出る → Enter でファイルを開く。

### ③ 現在ファイル内検索（Vim 標準）

**今開いているファイルだけ検索**。

```
/検索文字 Enter
```

→ ハイライト & ジャンプ

| キー | 動作 |
|---|---|
| `n` | 次のマッチへ |
| `N` | 前のマッチへ |
| `:noh` Enter | ハイライト消す |

### ④ カーソル下の単語を grep

```
Space → s → w
```

→ カーソル位置の単語でプロジェクト全文検索。

### ⑤ 最近開いたファイル

```
Space → f → r
```

→ Recent files の一覧。VSCode の「最近使ったもの」と同じ。

### Telescope 操作中のキー（fuzzy 検索ボックス内）

| キー | 動作 |
|---|---|
| `Ctrl+n` / `Ctrl+p` | 候補上下移動（矢印キーでも OK） |
| `Enter` | 選択して開く |
| `Ctrl+x` | 水平分割で開く |
| `Ctrl+v` | 垂直分割で開く |
| `Ctrl+t` | 新規タブで開く |
| `Esc` | キャンセル |

## 📑 開いてるファイル間の移動

| キー | 動作 | VSCode 対応 |
|---|---|---|
| **`Shift+L`** | 次のバッファ（次の開いてるファイル） | Ctrl+Tab |
| **`Shift+H`** | 前のバッファ | Ctrl+Shift+Tab |
| `Space b b` | バッファ一覧から選ぶ | Ctrl+P っぽい |
| `Space b d` | 現在のバッファを閉じる | Ctrl+W |
| `Space b D` | 強制閉じる | |
| `Ctrl+O` | 履歴を 1 つ戻る（カーソル位置含む） | Alt+← |
| `Ctrl+I` | 履歴を 1 つ進む | Alt+→ |

## 📝 編集の最低限

### 文字を入力する

1. Normal モードでカーソルを置きたい場所へ
2. `i` を押す → ステータス行に `-- INSERT --` が出る
3. 普通に入力
4. `Esc` で Normal モードに戻る

### 保存

```
:w<Enter>
```

または `Ctrl+S` （LazyVim では多くの場合有効）。

### Undo / Redo

| キー | 動作 |
|---|---|
| `u` | Undo（Normal モードで） |
| `Ctrl+R` | Redo（Normal モードで） |

### 行を消す

Normal モードで:

```
dd
```

→ 現在行を削除（クリップボードにも入る）。

### コピー＆ペースト

| キー | 動作 |
|---|---|
| `yy` | 行ヤンク（コピー） |
| `p` | カーソル位置の下に貼り付け |
| `P` | カーソル位置の上に貼り付け |
| `"+y` | OS クリップボードへコピー（Visual で範囲選択後） |
| `"+p` | OS クリップボードから貼り付け |

範囲選択は `v`（文字単位）/ `V`（行単位）/ `Ctrl+v`（矩形）で開始 → 移動 → `y` でヤンク。

## 🆘 困った時のリセット

| 状況 | 対処 |
|---|---|
| カーソルが暴れてる / どこ？ | `zz` で画面中央にカーソル行を持ってくる |
| 何モードか分からない | `Esc` を 3 回 → Normal に確実に戻る |
| 画面崩れた | `Ctrl+L` で再描画 |
| プラグインがおかしい | `:Lazy sync` でプラグイン更新 |
| LSP が動かない | `:LspInfo` でステータス確認、`:Mason` で LSP 再 DL |
| 真っ赤なエラー出てる | `:messages` Enter で最新エラー全文 |
| **全部わからん** | `:qa!` で強制終了 → ターミナルから `nvim` で再起動 |

## ✨ 最初の 1 週間の使い方推奨

1. **Day 1〜2**: `Space e` でファイラ開く → ファイル選んで `i` で編集 → `Esc :w` で保存。慣れる。
2. **Day 3〜4**: `Space f f` でファイル名検索、`Space /` で全文検索。VSCode 的に動かす。
3. **Day 5〜7**: `:Tutor` を一通りやって vim 基本キーバインド習得（30 分）。
4. **Day 8〜**: 徐々に `dd`、`yy`、`gd` 等の効率キーを使う。**ここで vim の威力を体感し始める**。

最初の数日は「マウス＋矢印キー＋Space メニュー」で十分。**急がない**。
