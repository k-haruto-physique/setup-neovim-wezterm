# 1 枚チートシート（毎日これだけ）

`docs/keybinds.md` は網羅版で巨大。これは **毎日触る最小セット**だけ。迷ったらまずこの 1 枚。
プリントするか、下モニターに常時表示する想定。

> 🚨 **詰まったら**: `Esc` 連打 → Normal に戻る ／ 効かない時は **IME OFF**（`Alt+~`）。`Esc` の代わりに **`Ctrl+[`**（IME 透過で確実）。

---

## モード（最初に体に入れる）

| キー | 動作 |
|---|---|
| `i` | 入力開始（カーソルの前） |
| `a` | 入力開始（カーソルの後） |
| `A` | **行末から**入力（超頻出） |
| `o` | 下に新規行を作って入力 |
| `Esc` / `Ctrl+[` | Normal に戻る（`Ctrl+[` は IME 透過で安全） |
| `:` | コマンド入力（`:w` `:q` など） |

---

## 移動（Normal モード）

| キー | 動作 |
|---|---|
| `←↓↑→` | 移動（最初はこれで OK、IME に強い） |
| `h j k l` | 同上（vim 流・IME ON だと奪われる） |
| `w` / `b` | 次 / 前の単語へ |
| `0` / `$` | 行頭 / 行末 |
| `gg` / `G` | ファイル先頭 / 末尾 |
| `Ctrl+d` / `Ctrl+u` | 半画面 下 / 上 |
| `zz` | カーソル行を画面中央へ（迷子復帰） |

---

## 編集（Normal モード）

| キー | 動作 |
|---|---|
| `x` | 1 文字削除 |
| `dd` | 1 行カット |
| `yy` / `p` | 行コピー / 貼り付け |
| `u` / `Ctrl+r` | 取り消し / やり直し |
| `ciw` | カーソル下の単語を丸ごと書き直し |
| `ci"` | クォート内側を書き直し（`ci(` `ci{` も同様） |
| `J` | 下の行を現在行に連結 |
| `>>` / `<<` | 右 / 左インデント |

---

## 保存・終了

| コマンド | 動作 |
|---|---|
| `:w` | 保存（このとき自動整形が走る） |
| `:q` | 終了 |
| `:wq` / `ZZ` | 保存して終了 |
| `:q!` | 破棄して強制終了（救済） |
| `:qa!` | 全部破棄して nvim 終了（最終手段） |

---

## ファイル・検索（LazyVim の Space メニュー）

> `Space` を押すと下にメニューが出る。**慌てず読む**。

| キー | 動作 | VSCode |
|---|---|---|
| `Space f f` | ファイル名で開く | Ctrl+P |
| `Space /` | プロジェクト全文 grep | Ctrl+Shift+F |
| `Space e` | ファイラ開閉（snacks explorer） | サイドバー |
| `Space f r` | 最近開いたファイル | — |
| `/文字` → `n`/`N` | 今のファイル内検索 → 次/前 | Ctrl+F |
| `:noh` | 検索ハイライト消す | — |

## WezTerm（ターミナル側・nvim の外）

| キー | 動作 |
|---|---|
| `Ctrl+Shift+Alt+"` | ペイン上下分割 |
| `Ctrl+Shift+←→↑↓` | 隣のペインへ移動 |
| `Ctrl+Shift+Z` | ペイン最大化トグル |
| `Ctrl+Shift+I` | 新ウィンドウで `nvim`（上モニター用） |
| `Ctrl+Shift+N` | 新ウィンドウで `claude`（下モニター用） |
| `Ctrl+Shift+X` | コピーモード（カーソル黄色化で判別・IME OFF 必須） |

---

## 困った時の 3 つ

1. **モードが分からない** → `Esc` 3 回 → Normal
2. **キーが効かない** → IME OFF（`Alt+~`）、または `Ctrl+[`
3. **どのキーか忘れた** → `Space` を押して which-key を読む
